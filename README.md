# FlipStack (Android test build)

FlipStack helps house flippers analyze a deal with real numbers. This is an early test build for Android.

## Install

1. On your Android phone, open this link to download the app: https://github.com/bigtrey33/flipstack-app/releases/latest/download/FlipStack.apk
2. When the download finishes, tap the file to install it.
3. If Android asks, allow installs from your browser (Install unknown apps), then tap Install. Play Protect may show a scan prompt; that is normal for apps outside the Play Store.
4. Open FlipStack, create an account, and try it.
